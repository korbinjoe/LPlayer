# LPlayer 可交互 HTML 视觉稿

入口：http://127.0.0.1:4178/

纯前端、无需 npm 依赖。双击或直接打开 index.html 可能受浏览器的本地文件限制，推荐运行：

```sh
python3 serve.py
```

主界面支持真实视频播放、进度定位、音量/静音、倍速、中英文演示字幕、缩放、浏览器全屏、紧凑/大图列表、选中项独立静音预览、空状态与本地视频打开。保留新版字体、色彩和布局，交互恢复原生原设计。内置演示影片可保留，列表默认关闭，也不会在首次载入本地视频时强制打开。

播放上下文：Space 播放/暂停，W/S 与 ↑/↓ 一致，切换上一个/下一个视频；A/D 与 ←/→ 一致，跳转 5 秒，按住 Shift 跳转 30 秒。音量使用滑块、Shift+W/S 或 Shift+↑/↓ 增大/减小，Q/E 每次减/增 0.1×（0.25–3×），R 正常速度。F 全屏，G 字幕，Z 撤销跳转，0 画面复原。切视频到边界停留，按住按键不连切。组合键严格匹配，Shift 调节音量时不会误触切视频，Command/Control/Option 组合不会触发普通字母动作。

列表可见即列表上下文：T 打开/收起；W/S 或 ↑↓ 仅改变选择并静音预览；A/D、J/L（对应左右手）及 ←/→ 不跳转主视频；Home/End 首尾；Space/Enter 确认。鼠标单击条目直接正式播放。确认当前播放项只继续播放，保留当前位置；确认之后仍保持列表模式，直到收起列表。列表与 Quick 互斥。

Quick：C 打开/收起，W/S 或 ↑↓ 选择，A/D 或 ←/→ 调整，Space/Enter 确认，Esc 收起。列表与 Quick 内的 Shift+方向操作仍用于选择或调整，不会调节主播放器音量。鼠标操作行内控件同步选中行；倍速主按钮直接打开 Quick 并聚焦首行，字幕主按钮直接开关字幕。原 15 项顺序为：速度、音量、缩放、灵敏度、显示字幕、字幕时间、音轨、字幕轨道、单手布局、无痕、打开、文件夹授权、列表、语言、快捷键设置。footer 设置入口也参与同一套单手导航。缩放每次 25%，范围 100%–500%。双指手势、灵敏度、音轨切换、文件夹持久授权和界面语言切换未在网页实现，明确标注“仅原生”，不能假操作。快捷键设置可查看默认键位，自定义录制只在原生 App 中使用，HTML 不模拟。

右手布局：I/K 与 ↑/↓ 一致，播放时切视频、列表和 Quick 中上下选择；J/L 与 ←/→ 一致，播放时跳转、Quick 中调整。音量为 Shift+I/K，U/O 倍速，P 正常速度，逗号打开 Quick，单引号或 B 打开列表，Y 帮助，H 全屏，分号字幕，M 撤销跳转。旧的 X/B、N/. 不再承担切视频动作。Quick 的“单手布局”仍能用单手直接切换，界面提示即时同步。

帮助是非模态右栏：V/Y、/、? 或 ⌘/ 打开/收起，Space 和播放快捷键仍可使用；Esc 收起。设置才使用模态窗口和焦点锁定。⌘O 打开，⌘L 列表，⌘, 设置，⌘[/⌘] 切视频，⌘N 无痕标识，⌃⌘F 全屏。鼠标双击画面没有额外全屏动作；原生双指缩放、双指轻点和移动画面不在 HTML 中模拟。红黄绿窗口按钮仅展示原生视觉并禁用，不用关闭影片或专注模式冒充关闭/最小化窗口。

内置三段演示视频由 AI 生成静帧与 FFmpeg 缓慢运镜制作，均为静音素材，不是实拍旅游视频。打开的本地文件仅通过浏览器 Object URL 播放，不上传。浏览器对 MKV 等格式的支持不等同于原生 libmpv。画面缩放、字幕与偏好用于原型体验；没有实现原生解码、字幕文件解析、文件夹授权或观看记录后端。

文件：index.html、style.css、app.js、dialogs.css、dialogs.js、assets/、serve.py。

图标采用 Phosphor Icons，源自 https://github.com/phosphor-icons/core，MIT 许可证保存在 assets/icons/LICENSE.txt。应用图标复用项目已有 Resources/LPlayer-icon.png。三个电影画面由本次内置 imagegen 生成，原始 PNG 已保留。

此目录仅包含可运行的视觉稿与资源，历史截图和本机验证记录不纳入源码。原生控制器的复现检查见仓库中的 `scripts/interaction/README.md`。

品牌字体对比（2026-10-24）：设置 → 品牌字体提供 Manrope、Outfit、Space Grotesk 三种字标字体；即时更新标题栏、应用菜单和设置中的 LPlayer 英文标识。默认 Manrope SemiBold 600。中文界面、功能标签与时间读数沿用系统字体。字体通过 fonts.css 从 assets/fonts/ 本地加载，随附各字体的 OFL 授权和 Google Fonts 分发元数据，不依赖外部 CDN。
