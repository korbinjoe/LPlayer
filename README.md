# LPlayer

面向 macOS 的本地视频播放器，提供左右手键盘预设。原生 AppKit 界面，libmpv 播放内核。支持打开文件或文件夹、播放定位、字幕与音轨选择、本机观看记录和断点恢复。

普通本地版 0.10.0 完成了一轮性能优化：预览销毁、目录与字幕扫描、观看记录写入移出主线程；连续输入保留最新意图，面板与控制栏复用已计算的内容。具体前后测量、实播结果、复现方式与限制见 [性能走查记录](docs/PERFORMANCE.md)。

## Mac App Store 沙盒预览

当前新增独立的 `dist/LPlayer Sandbox.app`（0.8.0，Apple Silicon，macOS 15+），用于验证去除 GPL-only 运行依赖的内核及 App Sandbox。它使用独立标识与数据容器。下方普通 Homebrew 开发构建的许可证和最低系统版本说明，不适用于这份沙盒包。

```sh
./scripts/build-store-deps.sh
./scripts/build-store-app.sh --preview
./scripts/check-store-app.py
```

沙盒版选择单个文件时只播放该文件。按 `⌘⇧O` 允许访问所在文件夹后，可使用同目录视频队列和匹配外挂字幕；授权通过本机只读安全书签保存。“文件”菜单可清除保存的授权。无痕模式不新增持久历史或授权。隐私政策可从“帮助”菜单离线查看。

构建脚本固定依赖源码及 SHA256，拒绝从普通 Homebrew mpv/FFmpeg 回退，独立编译并核对完整动态库闭包。对应源码与配置位于 `dist/LPlayer-0.8.0-dependency-sources.zip`。预览签名为本机 ad-hoc，尚未正式签名、上传或获 Apple 审核。发布配置和仍需准备的资料见 [发布准备](docs/APP_STORE_RELEASE.md)，实测范围见 [验证记录](docs/APP_STORE_VALIDATION.md)。

## 启动

需要 macOS 13 或更新版本、Xcode Command Line Tools、Homebrew。当前构建在 Apple Silicon Mac 上验证。

```sh
brew install mpv pkg-config
```

双击仓库里的 **打开LPlayer.command**。首次会自动构建，随后打开 `dist/LPlayer.app`；以后也可以直接双击这个 app。`.command` 会在源码更新后重新构建。

```sh
./scripts/build-app.sh
open dist/LPlayer.app
```

启动后显示带应用图标的空状态，可点击“打开视频…”、按 `⌘O` 或将文件拖入窗口；也可以直接体验三部内置演示短片。载入视频后收起空状态。还可以从 Finder 的“打开方式”选择 LPlayer；应用声明支持视频文件，但不会主动更改系统默认播放器。

主窗口使用 55 点标题栏和 99 点双层播放控制栏：进度条与时间位于上层，播放、跳转和调节入口位于下层。控制栏仅占据视频列的宽度，右侧列表独立延伸至窗口底部。常用图标使用中性色，蓝色表达开启、选中和焦点状态。快捷面板使用接近不透明的深色背景，普通界面文字采用系统字体，不添加通用阴影；视频上的字幕另行保留可读性保护。

设置使用左侧分类导航，分为“通用”“快捷键”和“关于”。从 **LPlayer → 设置…**、底栏“更多”或快捷面板底部进入；`⌘,` 直接打开快捷键页。“通用”提供界面语言、默认左右手布局和画面拖动灵敏度；快捷面板同时保留这些原有的单手操作入口。

## 界面语言

支持 **English** 和 **简体中文**。首次启动默认英文，不跟随 macOS 的系统语言；以后保留上次选择。在 **设置 → 通用 → 语言** 中切换，也可使用菜单 **LPlayer → Language / 语言**。

语言切换会即时更新菜单、控制按钮提示、快捷面板、播放列表、快捷键侧栏、缩略图提示和播放器错误说明。切换不改变视频文件、播放位置、倍速、缩放、单手布局或无痕状态；媒体文件名和字幕内容保持原样。原生系统对话框使用应用启动时选定的语言。

## 单手操作

| 操作 | 左手 WASD | 右手 IJKL |
| --- | --- | --- |
| 暂停 / 继续 | Space | Space |
| 后退 / 前进 5 秒 | A / D | J / L |
| 后退 / 前进 30 秒 | Shift + A / D | Shift + J / L |
| 增大 / 减小音量 | Shift + W / S | Shift + I / K |
| 降低 / 提高倍速 | Q / E | U / O |
| 恢复正常速度 | R | P |
| 全屏 | F | H |
| 字幕开关 | G | ; |
| 撤销上一次跳转 | Z | M |
| 快捷面板 | C | , |
| 快捷键帮助 | V | Y |
| 播放列表 | T | '（保留 B 兼容） |
| 上一个 / 下一个视频 | W / S | I / K |
| 画面恢复适应窗口 | 0 | 0 |

默认使用左手预设。在 **设置 → 通用 → 单手布局** 中切换左右手，选择会保留到下次启动。`W/A/S/D` 与 `↑/←/↓/→` 一一对应：播放时上下切视频、左右跳转，列表中上下选择，快捷面板中上下选择、左右调整；右手 `I/J/K/L` 同理。音量移到 `Shift+W/S` 或 `Shift+I/K`，`Q/E` 或 `U/O` 仍调节倍速，`R/P` 恢复正常速度。右手列表键为靠近 L 和分号的 `'`，仍可使用 B。组合键严格匹配，Shift 调整音量时不会误触切视频，Command/Control/Option 组合也不会触发普通字母动作。升级前已自定义的左右手布局分别保留原先实际生效的整套键位；在快捷键设置中恢复对应布局的默认值后，才启用新版预设。

按 `V`（左手）或 `Y`（右手），也可按 `?`，打开右侧快捷键提醒。打开时为侧栏单独留出空间，视频在左侧完整显示，不被提醒遮挡；关闭后恢复原播放区域。可再次按提醒快捷键、按 `Esc`，或点击侧栏关闭按钮收起。窗口缩小及全屏时仍保持分区；空间不足时快捷键列表可以滚动。帮助是非模态的说明侧栏，可边看边操作；播放键继续生效，`↑/↓` 仍切换视频，查看更多说明请滚动侧栏。帮助直接显示当前左右手或自定义主绑定，方向键等固定兼容键保留在完整提示中，并提供捏合、双指双击和平移手势说明。

播放列表默认收起，按需打开。按 `T`（左手）或 `'`（右手，兼容 `B`）、`⌘L`，或点击顶部侧栏按钮，可切换显示。列表与视频各占独立区域；蓝色侧标表示当前视频，选中项另用轮廓标记。

鼠标单击条目即在主播放器中打开该视频，无需双击或再次确认；缩略图上的播放图标也是同一入口。连续双击的第二次按下不会重复开播。在列表浏览时，可用 `W/S`（左手）、`I/K`（右手）或 `↑/↓` 移动选择，回车或空格确认播放，`Home/End` 选择首项或末项。再次按列表快捷键、按 `Esc` 或点击顶部侧栏按钮可收起。确认播放当前视频会继续播放，不会从头重播；已到片尾的当前视频可重新播放。

播放列表默认使用 284 点宽的紧凑布局，约 68 点行高，76×44 点缩略图旁显示文件名、状态和已知时长；未知时长显示占位，预览或播放后补齐。顶部视图切换可改为 320 点宽的大图布局，选择会保存。过长的文件名从中间省略，悬停可看完整文件名或路径。侧栏还提供文件夹名称、打开文件入口和底部快捷键提示。静态封面最高 640×360 像素，仅异步加载可见条目，内存缓存仍限制为 24MB，不写入磁盘。

用键盘选中条目并停留约 220 毫秒后，其缩略图自动开始静音动态预览，并显示“Muted preview / 静音预览”。快速连续切换只加载最后停留的项。整个列表仅使用一个动态预览引擎，初始化时即禁用音频轨和声音输出；预览不修改主视频、播放历史和音量。鼠标单击或键盘确认正式播放后，动态预览停止，直到下一次键盘选择；列表保持打开，导航键仍用于浏览，不会转为调节音量或跳转。条目滚出屏幕、列表关闭、窗口进入后台或主视频快进时释放动态预览，保留静态封面；重新选中或恢复浏览后按需继续。

按 `C` 打开左手快捷面板，`W/S` 选择、`A/D` 调整、空格或回车执行，`C` 收起。右手对应 `,`、`I/K`、`J/L`；也可以使用方向键。快捷面板与播放列表互斥，打开其中一个会收起另一个，键盘确认始终属于当前可见模式。面板保留原来的 15 项和顺序：播放速度、音量、画面缩放、拖动灵敏度、显示字幕、字幕时间、音轨、字幕轨道、单手布局、无痕播放、打开文件或文件夹、文件夹访问、播放列表、语言、自定义快捷键。新版样式将这些项目分为“播放”“画面”“字幕与音轨”“通用”四组。各项使用真实的菜单、滑块、开关、步进或操作按钮，也可直接用鼠标操作；字幕时间每次调整 0.1 秒。面板标题和底部导航固定，内容区域可滚动，键盘选中项会自动滚入视野。固定的“设置…”入口是第 16 个键盘目标，上下导航可从末项回绕；完整操作说明可通过悬停查看。

快捷面板打开时，`W/S` 或 `I/K` 用于选择项目，`A/D` 或 `J/L` 调整当前值，回车或空格执行复原或切换；`Esc` 关闭当前面板或侧栏，再退出全屏。语言、默认左右手布局、拖动灵敏度、无痕和文件夹授权均保留快捷面板入口，同时可从设置或相关菜单进入。底栏字幕按钮单击直接开关字幕；倍速按钮打开快捷面板并选中“播放速度”，随后可用 `A/D` 或 `J/L` 连续调整。

播放时，`W/S`（左手）或 `I/K`（右手）与 `↑/↓` 一样切换上一个 / 下一个视频；`A/D` 或 `J/L` 与 `←/→` 一样后退 / 前进 5 秒，配合 Shift 跳转 30 秒。音量使用滑块、`Shift+W/S`（左手）、`Shift+I/K`（右手）或 `Shift+↑/↓` 调整。播放列表可见时，上下键移动选择，回车或空格确认播放；播放后列表仍拥有这些导航键。快捷面板可见时，上下键选择调节项。列表或面板中的 Shift+方向操作仍用于当前可见模式的导航或调整，不会误调主播放器音量；关闭当前模式后恢复播放命令。持续按住切视频键不会连续跳过多个视频。

`⌘O` 打开视频或文件夹，`⌘[` / `⌘]` 也可切换上一个 / 下一个视频。文件选择对话框及文本输入时，字母键正常输入，不触发播放命令。

快进首次按下立即响应；按住或连续点击时会持续更新累计目标，并合并来不及完成的中间请求。播放中等待上一轮精确定位完成后处理最新目标，暂停时直接定位；最终仍保留 5 秒 / 30 秒的精确步长。跳转期间暂停缩略图解码，恢复播放后再提供悬停预览。长关键帧间隔或高分辨率视频的精确跳转仍需要解码时间。

在视频上使用触控板双指捏合，可从适应窗口连续放大到 5 倍，以手势开始时的指针位置为中心查看细节。放大后无需按下触控板，双指滑动即可移动画面：画面始终跟随手指方向，松手即停，不随系统滚动方向设置反转，也不继续惯性漂移。默认每个手势点移动一个画面点，不随缩放倍率或 Retina 分辨率增加速度；在 **设置 → 通用 → 拖动灵敏度** 中可调整 25%–150%，并恢复为 100%，选择会自动保存。到达视频边缘会停止，不会拖出新的黑边；宽屏或竖屏视频中仍能完整显示的轴保持居中。一次手势在视频上开始后，指针经过控制栏也不会突然中断；在播放列表、快捷键侧栏或控制栏开始的手势保留原有操作。画面更新只保留最新目标，跳过未变化的缩放属性，避免连续输入排队后延迟追赶。

放大后的左下角会出现紧凑提示，显示倍率、双指移动方法和当前实际复原快捷键；提示穿透鼠标事件，与控制栏一起自动隐藏。向内捏合缩小；双指双击可在 2 倍放大与适应窗口之间切换。默认按 `0` 或 `⌘0` 随时复原，也可以在快捷面板的“缩放”行用左右键调整、空格复原。缩放和拖动只改变视频画面，不改变窗口、控制栏、播放速度或进度；切换视频自动复原，不写入观看记录。

鼠标悬停在进度条上，会显示对应时间的缩略图和时间码；移出后收起。预览由独立的低分辨率解码器生成，不改变正在播放的视频进度，支持 MP4、MKV 等播放器可解码格式。快速移动时以 80 毫秒为首轮调度间隔处理最新目标，不再因持续移动一直延后；等待新图时保留上一张图并标记加载中。复用当前视频的内存缓存，不会将缩略图写入磁盘。无法提取画面时显示时间码和提示，仍可正常点击跳转。

## 自定义快捷键

按 `⌘,` 直接打开设置的“快捷键”页，也可从 **LPlayer → 设置…**、底栏“更多”或快捷面板底部进入设置后选择“快捷键”。支持搜索 29 个操作，分别编辑左右手布局。点击按键按钮开始录制，可用字母、数字、功能键及 Command / Option / Control / Shift 组合；按 Esc 取消录制、Delete 清除当前主绑定。单项清除和重置收在该行的更多操作中，也可恢复当前布局全部默认值。修改即时生效并自动保存在本机，下次启动继续使用。

重复按键或系统保留组合会显示原因，保留原有设置。方向键、回车、Esc、面板内的 WASD / IJKL 导航，以及 ⌘O、⌘L、⌘, 等固定兼容键不会被重新分配；清除只移除可编辑的主绑定。文件授权的 ⌘⇧O 也保留给原生菜单。编辑器和文本输入期间，按键不会触发后台播放操作。

快捷键帮助、按钮提示和播放列表导航说明随自定义结果更新。面板内仍可用固定方向键选择和调节、回车或空格执行，不会因修改播放快捷键失去导航能力。

## 继续观看与无痕

音量是播放器的全局设置：键盘、底栏滑块和快捷面板的调整对所有视频生效，切换文件、自动连播、普通/无痕切换或重新打开播放器时保持。旧观看记录中的音量字段仅为格式兼容保留，不再恢复并覆盖当前音量。

普通模式将最近 30 个文件的进度、倍速、字幕延迟、字幕显示与音轨选择保存在本机 `~/Library/Application Support/PalmPlayer/history.json`。内存记录即时更新，编码与写入在后台合并进行，进入无痕、休眠和正常退出前完成保存。再次打开文件会恢复；已到片尾的文件从头开始。改名为 LPlayer 后保留原有应用标识、历史目录与偏好。

普通本地版单独打开一个视频时，先启动选中的视频，再在后台将当前目录的所有可播放视频加入播放列表，按自然文件名排序（例如第 1、2、10 集）；补全列表不会重新加载当前视频。外挂字幕同样在后台匹配，延迟到达的结果不会覆盖已作出的手动字幕选择。Finder 打开、拖入文件、文件选择框和最近打开使用相同行为，无需先手动打开整个文件夹。只读取当前层，忽略隐藏文件、子文件夹和非视频文件；自动推导的目录访问仅在本次运行有效，不保存为目录授权。打开文件夹时同样只展开当前层的视频；一次选择多个文件时保留选定顺序。播放完毕后进入列表中的下一项。沙盒版受系统权限限制，首次仍需选择或授权所在文件夹。

在底栏“更多”或“文件”菜单选择“无痕播放”，或按 `⌘N` 开关无痕；顶部仅在开启时显示无痕标记。开启前会先保存当前普通模式进度；开启期间不写入观看记录，也不从历史恢复，新打开的视频从头播放。已有历史不会被删除，退出无痕后继续使用普通记录。可在“文件”菜单清空观看历史。

## 合成演示素材

空状态和 LPlayer 菜单可打开三部内置演示短片，位于 `Resources/Demo`，随普通版与沙盒版一起打包。这些是 AI 生成的冰岛风景静帧，经 FFmpeg 缓慢推移制成的无声短片，并配有 SRT 字幕，**不是实地摄影片段**。来源说明见 [演示素材说明](Resources/Demo/README.txt)。

另有用于播放与定位检查的本地合成素材，可按下列命令生成：

```sh
brew install ffmpeg
./scripts/make-demo.sh
```

生成到 `artifacts/demo`：两集 48 秒、1280×720 的 MP4 / MKV，带计时和移动箭头；中英外挂字幕，MKV 另带内嵌双字幕。素材完全本地合成，包含低音量测试音。可用于检查播放、定位、倍速、字幕选择和连续打开。

```sh
./scripts/check-core.sh

python3 scripts/interaction/run-controller.py
```

`check-core.sh` 检查键位映射、面板命令和观看记录等核心逻辑，不使用个人历史目录。`check-engine.sh` 编译独立的 libmpv 检查程序，实播约 8 秒并短暂显示视频窗口，检查播放与渲染管线；不会操作主应用界面或个人观看记录。也可用 `./scripts/check-engine.sh '/绝对路径/视频.mkv'` 检查自己的媒体。

`scripts/interaction/run-controller.py` 检查当前真实控制器的本地按键事件、WASD / IJKL 与方向键对应关系、Shift 音量、长按与首尾保护、侧栏互斥、原有 15 项快捷面板与固定设置入口。测试副本始终隐藏，只读取临时合成素材，使用隔离偏好、历史和授权目录；源码哈希、适配说明与运行结果写入忽略版本控制的 `artifacts/controller-check/`。覆盖范围见[控制器检查说明](scripts/interaction/README.md)。此检查不代表物理键盘或真实窗口焦点、全屏 Space 和系统对话框验证。

`check-viewport.sh` 检查锚点、留黑边、缩放与拖动边界及窗口尺寸变化的几何计算。`check-gestures.sh` 使用本地合成视频、独立 AppKit 窗口和合成的原生手势事件，验证缩放、复原及实际渲染变化；不会读取个人媒体或操作正在使用的播放器。物理触控板的手感仍需在设备上体验。

`check-thumbnails.sh` 使用合成 MP4 / MKV 验证实际缩略图、悬停位置映射、取消与切换文件、预览组件及播放期间的独立解码，不读取个人媒体。

`check-seeking.sh` 使用合成 1080p 长 GOP 视频验证精确跳转、连续输入、暂停状态与文件替换，并记录定位完成和实际新帧显示的耗时。基准样片、报告及测量边界位于 `artifacts/seek-benchmark/`；单个合成样片的表现不能代表全部视频。

左右手预设、面板、撤销跳转、全屏和输入对话框不误触已在主应用中实际操作验证。上述脚本用于可重复的逻辑与播放检查，不能替代完整界面或所有媒体兼容性测试。

## HTML 视觉稿

可交互视觉稿保存在 [`prototypes/lplayer`](prototypes/lplayer/README.md)，无需 npm 依赖。从仓库根目录启动：

```sh
python3 prototypes/lplayer/serve.py
```

然后访问 `http://127.0.0.1:4178/`。视觉稿使用本地视频、字体与图标，帮助文字和方向键操作与原生版本同步；网页未实现的原生能力有明确标注。该端口已被其他预览占用时，请先结束相应的预览服务后再启动。

## 构建与分发边界

`build-app.sh` 只递归复制可执行文件真正依赖的非系统动态库，重写为 app 内相对路径，并进行本机 ad-hoc 签名。构建在独立暂存目录完成，校验后备份旧版并原子替换 `dist/LPlayer.app`；正在运行的播放器不被重启，新功能在下次正常启动后生效。不会复制 Homebrew 包目录、用户媒体或配置。打包后的 app 不应依赖 Homebrew 路径。

标题栏的 **LPlayer 英文字标使用 Manrope SemiBold（600 字重）**，以 13 点字号和轻微紧字距呈现；中文、播放控制和时间读数使用系统字体。字体和 OFL 授权随普通版与沙盒版一起打包，无需在系统中安装。

图标采用用户选定的第一版圆润轮廓方案：珊瑚红扁平圆角底，奶油白标记由连续的左竖边与下侧上扬斜边构成 L，独立的上斜边在两端留出间隙，整体形成播放三角。原画 `Resources/LPlayer-icon.png` 使用内置 imagegen 生成并保留透明通道，完整设计和抠图提示词保存在 `Resources/LPlayer-icon.prompt.txt`。选定的预览与透明生产稿保存在 `Resources/icon-explorations/2026-10-24/designed/`。`scripts/make-icon.sh` 只将原画缩放为 macOS 标准尺寸并输出 `Resources/LPlayer.icns`。仅更新图标时运行 `scripts/install-icon.sh`，也可传入一个或多个应用路径：它会备份现有应用、在副本中更新图标并保留沙盒签名权限，验证后原子替换应用包，保留正在播放的进程。运行中的 Dock 图标可能在下次正常启动后刷新。

第三方版本、配方、源码网址、可找到的许可原文和实际 FFmpeg 许可报告位于 `Resources/licenses`，打包后也放入 app 的同名资源目录。运行 `./scripts/build-app.sh --licenses-only` 只刷新资源，不编译或启动播放器。当前本机 FFmpeg 使用 GPL-3.0-or-later 构建，所带组件不是仅 LGPL 的组合；该清单不是完整对应源码交付或发行合规证明。

这是本地开发版本，尚未进行 Developer ID 签名、公证和独立安装包发布。当前视频渲染使用 libmpv 的 OpenGL 管线，尚未实现 Metal 渲染；HDR 色彩正确性、各类音轨透传、所有编解码格式和跨设备功耗尚未专项验证。自动字幕时间校准、在线字幕搜索和 AI 功能尚未实现。媒体兼容性取决于本机 libmpv / FFmpeg 构建；对外分发前须检查所带依赖的许可证与对应源码要求。
