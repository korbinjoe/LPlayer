# LPlayer

[English](README.md) · **简体中文** · [日本語](README.ja.md) · [Français](README.fr.md) · [Deutsch](README.de.md) · [Español](README.es.md)

基于 AppKit 和 libmpv 构建的 macOS 本地视频播放器。通过快捷键流畅地切换视频、跳转进度和控制播放，让你专注于观看体验。

## 功能

- **快捷键操作。** 以灵敏、可自定义的快捷键浏览视频、跳转进度和调整播放参数。
- **本地播放。** 打开文件或文件夹、拖入视频，或从 Finder 打开。标准版会在后台发现同目录视频及匹配字幕。
- **列表预览。** 单击视频即可播放，也可用键盘浏览，在确认前查看静音缩略预览。提供紧凑列表和大图预览布局。
- **全局音量。** 音量调整对所有视频生效，切换文件和重启应用后均保持。视频旧记录中的音量不会覆盖当前设置。
- **续播与无痕播放。** 按文件恢复进度、倍速、字幕和音轨选择。无痕播放不新增观看历史或持久文件授权。
- **触控板与时间轴。** 双指捏合最高放大至 5 倍，双指移动画面；悬停时间轴可查看独立缩略预览。
- **原生界面。** AppKit 控件、自动隐藏的播放控制栏、Manrope 品牌字标，以及非模态快捷键提醒侧栏。

应用界面目前支持 **English（英语）** 和 **简体中文**。上方 README 翻译仅代表文档语言，不会增加应用界面语言。

## 构建与运行

需要 macOS 13 及以上版本、Xcode Command Line Tools 和 Homebrew。标准本地构建已在 Apple Silicon 上验证。

在仓库根目录运行：

```sh
brew install mpv pkg-config
./scripts/build-app.sh
open dist/LPlayer.app
```

也可双击 [`打开LPlayer.command`](打开LPlayer.command)。启动器会在需要时构建并打开应用；源文件变更后会重新构建。

启动后，点击 **打开视频…**、按 `⌘O`、将视频拖入窗口，或试播内置的三部演示短片。可以在 Finder 的 **打开方式** 菜单中选择 LPlayer；应用不会自动更改系统默认播放器。

这是使用临时签名（ad-hoc signing）的本地开发构建。目前尚未发布经 Developer ID 签名和公证的安装程序。

## 语言与设置

应用默认以 **英语** 启动，不跟随 macOS 语言，并会记住你的选择。可在 **设置 → 通用 → 语言**，或 **LPlayer → 语言** 中切换英语和简体中文。

更改语言后，菜单、工具提示、快捷控制、播放列表、快捷键帮助和播放错误信息会随之更新。媒体文件名和字幕文本保持原样。原生系统对话框使用应用启动时选定的语言。

设置包含 **通用**、**快捷键** 和 **关于**。可从 **LPlayer → 设置…**、播放控制栏的 **更多** 菜单，或快捷控制面板底部打开。`⌘,` 会直接打开 **快捷键** 页面。通用设置还包括默认单手布局和画面移动灵敏度。

## 键盘操作

下表为当前默认预设。此前已自定义的布局在升级时会保留原有的实际绑定；重置某一手的快捷键后，该手会采用新版默认值。

| 操作 | 左手 | 右手 |
| --- | --- | --- |
| 播放 / 暂停 | `Space` | `Space` |
| 上一个 / 下一个视频 | `W` / `S` | `I` / `K` |
| 后退 / 前进 5 秒 | `A` / `D` | `J` / `L` |
| 后退 / 前进 30 秒 | `Shift+A` / `Shift+D` | `Shift+J` / `Shift+L` |
| 增大 / 减小音量 | `Shift+W` / `Shift+S` | `Shift+I` / `Shift+K` |
| 降低 / 提高倍速 | `Q` / `E` | `U` / `O` |
| 正常倍速 | `R` | `P` |
| 播放列表 | `T` | `'`（也可用 `B`） |
| 快捷控制 | `C` | `,` |
| 快捷键帮助 | `V` | `Y` |
| 全屏 | `F` | `H` |
| 开关字幕 | `G` | `;` |
| 撤销进度跳转 | `Z` | `M` |
| 放大 / 缩小画面 | `=` / `-` | `=` / `-` |
| 画面适应窗口 | `0` | `0` |

`W/A/S/D` 和 `I/J/K/L` 分别对应 `↑/←/↓/→`，行为由当前可见模式决定：

| 模式 | 上 / 下 | 左 / 右 | Space / Enter |
| --- | --- | --- | --- |
| 播放 | 上一个 / 下一个视频 | 跳转 5 秒 | Space 播放 / 暂停 |
| 播放列表 | 选择并静音预览 | 跳转当前视频 5 秒 | 播放选中项 |
| 快捷控制 | 选择控制项 | 调整当前值 | 执行操作或重置控制项 |

播放时，`Shift+↑/↓` 调节音量，`Shift+←/→` 跳转 30 秒，与对应字母键一致。播放列表仅保留上下方向用于选择；左右键始终跳转当前正在播放的视频，即使选中了其他条目。Shift 加左右键跳转 30 秒，长按跳转键可连续调整。快捷控制中的所有方向键及其 Shift 组合仍用于选择或调整。长按切视频按键不会连续跳过多个视频。

其他快捷键：

- `⌘O`：打开视频或文件夹。
- `⌘L`：打开或收起播放列表。
- `⌘[` / `⌘]`：上一个 / 下一个视频。
- `⌘N`：开关无痕播放。
- `0` 或 `⌘0`：画面适应窗口。
- `?`、`/` 或 `⌘/`：打开或收起快捷键帮助。
- `Esc`：先关闭当前面板或侧栏，再退出全屏。

快捷键帮助为非模态侧栏：打开时仍可使用播放命令。文件对话框和可编辑文本框保留正常文字输入。

### 播放列表与快捷控制

播放列表默认关闭。鼠标单击条目会立即播放；键盘导航会先选中条目，短暂停留后开始静音预览。`Home` / `End` 选择第一项 / 最后一项。Enter 或 Space 确认后仍保持列表导航模式。确认当前视频会从当前位置继续播放；已结束的视频可以重新开始。

播放列表与快捷控制面板互斥。快捷控制保留 15 项操作：倍速、音量、缩放、画面移动灵敏度、字幕显示、字幕时间、音轨、字幕轨道、单手布局、无痕播放、打开文件或文件夹、文件夹授权、播放列表、语言及快捷键自定义。固定的 **设置…** 底栏入口也参与键盘导航。

字幕按钮直接开关字幕。倍速按钮打开快捷控制并选中倍速项；使用左右导航键，以每次 0.1 倍的步幅调整。

### 自定义快捷键

在 **设置 → 快捷键** 中，可搜索 29 项操作，并分别为左右手录制绑定。支持字母、数字、功能键和修饰键组合。按 Esc 取消录制，按 Delete 清除可编辑的主绑定。冲突和保留快捷键会被拒绝；固定导航键及菜单备用快捷键仍可使用。更改立即生效并保存在本机。

## 音量、历史与隐私

音量是所有文件共用的播放器级偏好，包括无痕播放，并在重启应用后保持。旧播放记录中的音量字段仅为格式兼容而保留，不再恢复。

普通播放将最近的 30 个文件保存在 `~/Library/Application Support/PalmPlayer/history.json`，并恢复进度、倍速、字幕时间与显示状态，以及选中的音轨和字幕轨道。已完成的视频从头开始。历史记录在后台写入；原应用标识和历史记录路径继续兼容早期的 PalmPlayer 名称。

标准本地版会立即打开选中的文件，随后发现同目录视频及匹配字幕，不阻塞播放。仅扫描当前目录，跳过隐藏文件及子目录，并按自然顺序排序，例如第 1、2、10 集。明确选择多个文件时，会保留选择顺序。视频结束后自动播放队列中的下一项。

启用无痕播放前会先保存正常播放进度，之后不再为新打开的文件读取或写入播放历史。这些文件从头开始；已有历史记录仍保留。全局音量和应用偏好仍会保存。可从 **文件** 菜单清除观看历史。

## 触控板与预览

在视频上捏合手势，可围绕指针位置缩放。放大后，双指在触控板上滑动，无需按下，即可移动画面；画面跟随手指，手指离开后停止。移动灵敏度可在 25% 至 150% 之间调整，默认为 100%。画面不会移出可用边界，切换视频会重置缩放和位移。

按 `=`（也可用 `+`）放大画面，按 `-` 缩小，每次调整 25 个百分点，范围为 100% 至 500%；长按可连续调整。左右手布局的默认键位相同，也可在设置中自定义。

双指轻点两次可在 2 倍缩放与适应窗口间切换，也可按 `0` / `⌘0` 重置。从播放列表、控制区域或帮助侧栏开始的手势，仍由对应界面处理。

时间轴缩略图使用独立的低分辨率解码器和内存缓存，不改变主视频的播放位置。列表动态预览同样独立运行并关闭音频。预览图像不会写入磁盘。

## 可交互 HTML 视觉稿

仓库在 [`prototypes/lplayer`](prototypes/lplayer/README.md) 中包含一个纯前端原型。它使用本地视频、字体和图标，无需 npm 依赖：

```sh
python3 prototypes/lplayer/serve.py
```

打开 <http://127.0.0.1:4178/>。原型目前使用中文界面。键盘操作模式与原生播放器一致，需要原生解码或 macOS API 的能力均有标注。本地文件通过浏览器 Object URL 播放，不会上传；浏览器格式支持与 libmpv 不同。原型未实现原生历史记录或文件授权后端。

三部内置演示短片由 AI 生成的风景静帧、FFmpeg 缓慢运镜和 SRT 字幕制作而成，均为静音素材，**不是实地拍摄视频**。详见[演示素材来源说明](Resources/Demo/README.txt)。

## 验证

额外的播放检查需要 FFmpeg 命令行工具：

```sh
brew install ffmpeg
./scripts/check-core.sh
./scripts/check-viewport.sh
./scripts/make-demo.sh
./scripts/check-engine.sh
./scripts/check-gestures.sh
./scripts/check-thumbnails.sh
./scripts/check-seeking.sh production-final Sources/PalmPlayer
python3 scripts/interaction/run-controller.py
```

核心检查覆盖键位映射、修饰键、历史记录、持久化和快捷键迁移。[控制器测试夹具](scripts/interaction/README.md) 使用生成的媒体和隔离存储，验证实际事件处理器，包括在带历史记录的文件间切换及重启后保持全局音量。生成报告保存在被忽略的 `artifacts/` 目录中；历史验证材料不随源码打包。

引擎和手势检查可能短暂显示独立测试窗口。隐藏运行的控制器测试夹具使用本地事件，不能证明实体键盘输入、前台焦点、全屏空间或系统对话框的行为。这些检查不能替代真实设备和媒体测试。此前测量结果及验证范围见[性能说明（中文）](docs/PERFORMANCE.md)。

## 沙盒预览与分发

独立的沙盒预览版使用受控依赖、单独的应用标识和容器，文档目标为 Apple Silicon 和 macOS 15 及以上版本。它尚未提交至 Mac App Store，也未获得商店审核通过：

```sh
./scripts/build-store-deps.sh
./scripts/build-store-app.sh --preview
./scripts/check-store-app.py
```

沙盒版最初只播放选中的文件。按 `⌘⇧O` 授予文件夹只读访问权限，以发现同目录视频和匹配字幕；授权使用安全作用域书签，可从文件菜单清除。无痕模式不新增持久授权或观看历史。

标准版会打包可执行文件实际使用的非系统库，重写加载路径、验证依赖，并对应用进行临时签名。构建会先保留备份，再原子替换 `dist/LPlayer.app`，不会重启正在运行的播放器。随附的 Manrope 字体无需安装到系统。

依赖版本与许可证声明位于 [`Resources/licenses`](Resources/licenses/README.md)。基于 Homebrew 的标准构建包含 GPL 许可组件；沙盒版使用独立的依赖配置。附带声明并非完整的对应源码分发。详见[发布准备（中文）](docs/APP_STORE_RELEASE.md)和[历史沙盒验证（中文）](docs/APP_STORE_VALIDATION.md)。

渲染器目前使用 libmpv 的 OpenGL 管线。Metal 渲染、在线字幕搜索、自动字幕时间校准和 AI 功能尚未实现。HDR 正确性、音频直通、所有编码格式和跨设备功耗尚未得到全面验证。
