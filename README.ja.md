# LPlayer

[English](README.md) · [简体中文](README.zh-CN.md) · **日本語** · [Français](README.fr.md) · [Deutsch](README.de.md) · [Español](README.es.md)

AppKit と libmpv で構築した、macOS 向けのローカル動画プレーヤーです。キーボードショートカットで動画の切り替え、シーク、再生をスムーズに操作でき、動画に集中できます。

## 特長

- **キーボードショートカット。** 反応がよく、カスタマイズもできる操作で、動画の切り替え、シーク、再生調整をスムーズに行えます。
- **ローカル再生。** ファイルやフォルダを開く、動画をウインドウにドロップする、Finder から開くといった操作に対応します。標準ビルドは同じフォルダの動画と対応する字幕をバックグラウンドで検索します。
- **プレイリストのプレビュー。** 動画をクリックすると再生し、キーボードで選択すると、確定する前に無音のサムネイルプレビューを表示します。コンパクト表示と大きなプレビュー表示を選べます。
- **すべての動画に共通する音量。** 音量調整はすべての動画に適用され、ファイルの切り替えやアプリの再起動後も維持されます。動画に残っている古い履歴が現在の音量を上書きすることはありません。
- **続きから再生とプライベート再生。** ファイルごとに再生位置、速度、字幕、音声トラックの選択を復元します。プライベート再生では視聴履歴や永続的なファイルアクセス権を追加しません。
- **トラックパッドとタイムライン。** ピンチで最大 5 倍に拡大し、2 本指でパンできます。タイムラインにポインタを合わせると、独立したサムネイルプレビューを表示します。
- **ネイティブな表示。** AppKit のコントロール、自動的に隠れる再生コントロール、Manrope を使ったワードマーク、モードレスのショートカット参照サイドバーを備えています。

アプリの UI は現在、**英語**と**簡体字中国語**に対応しています。上記の README 翻訳はドキュメントの言語であり、アプリの UI 言語を追加するものではありません。

## ビルドと起動

macOS 13 以降、Xcode Command Line Tools、Homebrew が必要です。標準のローカルビルドは Apple Silicon で検証しています。

リポジトリのルートから実行します。

```sh
brew install mpv pkg-config
./scripts/build-app.sh
open dist/LPlayer.app
```

[`打开LPlayer.command`](打开LPlayer.command) をダブルクリックしても起動できます。ランチャーは必要に応じてアプリをビルドして起動し、ソースに変更があれば再ビルドします。

起動後は **Open Video…**、`⌘O`、ウインドウへの動画のドロップ、または同梱された 3 本のデモ動画を利用できます。Finder の **このアプリケーションで開く**メニューで LPlayer を選択できます。システムの既定プレーヤーを自動で変更することはありません。

これはアドホック署名を使用するローカル開発ビルドです。Developer ID で署名し、公証を受けたインストーラは公開していません。

## 言語と設定

アプリは macOS の言語とは独立して、初回は**英語**で起動し、その後は選択した言語を記憶します。**Settings → General → Language** または **LPlayer → Language** から、英語と簡体字中国語を切り替えられます。

言語を変更すると、メニュー、ツールチップ、クイックコントロール、プレイリスト、ショートカットヘルプ、再生エラーメッセージが更新されます。メディアのファイル名と字幕本文は元のままです。ネイティブのシステムダイアログは、アプリ起動時に選択されていた言語を使用します。

設定には **General**、**Shortcuts**、**About** があります。**LPlayer → Settings…**、再生コントロールの **More** メニュー、またはクイックコントロールの下部から開けます。`⌘,` は **Shortcuts** ページを直接開きます。一般設定では既定の片手レイアウトとパン感度も変更できます。

## キーボード操作

以下は現在の既定プリセットです。以前にカスタマイズしたレイアウトは、アップグレード後も有効な割り当てを維持します。各手のショートカットをリセットすると、新しい既定値に置き換わります。

| 操作 | 左手 | 右手 |
| --- | --- | --- |
| 再生 / 一時停止 | `Space` | `Space` |
| 前 / 次の動画 | `W` / `S` | `I` / `K` |
| 5 秒戻る / 進む | `A` / `D` | `J` / `L` |
| 30 秒戻る / 進む | `Shift+A` / `Shift+D` | `Shift+J` / `Shift+L` |
| 音量を上げる / 下げる | `Shift+W` / `Shift+S` | `Shift+I` / `Shift+K` |
| 再生速度を下げる / 上げる | `Q` / `E` | `U` / `O` |
| 通常の再生速度 | `R` | `P` |
| プレイリスト | `T` | `'`（`B` も使用可） |
| クイックコントロール | `C` | `,` |
| ショートカットヘルプ | `V` | `Y` |
| フルスクリーン | `F` | `H` |
| 字幕の表示切り替え | `G` | `;` |
| シークを元に戻す | `Z` | `M` |
| 映像を拡大 / 縮小 | `3` / `2`（`=` / `-` も使用可） | `9` / `8`（`=` / `-` も使用可） |
| 動画をウインドウに合わせる | `1` / `0` | `7` / `0` |

`W/A/S/D` と `I/J/K/L` は `↑/←/↓/→` に対応します。動作は表示中のモードに従います。

| モード | 上 / 下 | 左 / 右 | Space / Enter |
| --- | --- | --- | --- |
| 再生 | 前 / 次の動画 | 5 秒シーク | Space で再生 / 一時停止 |
| プレイリスト | 選択して無音プレビュー | 再生中の動画を 5 秒シーク | 選択した項目を再生 |
| クイックコントロール | コントロールを選択 | 値を調整 | コントロールを実行またはリセット |

再生中は `Shift+↑/↓` で音量調整、`Shift+←/→` で 30 秒シークとなり、対応する文字キーと同じ動作をします。プレイリストでは上下方向だけを項目選択に使用し、左右キーは別の行が選択されていても現在再生中の動画をシークします。Shift と左右キーで 30 秒シークし、押し続けると繰り返します。クイックコントロールでは Shift を含むすべての方向キーを選択や調整に使用します。動画切り替えキーを押し続けても、複数の動画を連続してスキップしません。

その他のショートカット：

- `⌘O`：動画またはフォルダを開く。
- `⌘L`：プレイリストの表示を切り替える。
- `⌘[` / `⌘]`：前 / 次の動画。
- `⌘N`：プライベート再生を切り替える。
- `0` または `⌘0`：映像をウインドウに合わせる。
- `?`、`/`、または `⌘/`：ショートカットヘルプを切り替える。
- `Esc`：開いているパネルやサイドバーを閉じ、その後フルスクリーンを終了する。

ショートカット参照はモードレスで、開いている間も再生操作を利用できます。ファイルダイアログと編集可能なテキスト欄では、通常の文字入力が優先されます。

### プレイリストとクイックコントロール

プレイリストは初期状態では閉じています。行をマウスでクリックすると即座に再生します。キーボード操作では行を選択し、少し待つと無音プレビューを開始します。`Home` / `End` で最初 / 最後の項目を選択できます。Enter または Space で確定しても、プレイリストのナビゲーションは継続します。現在の動画を確定すると現在位置から再開し、再生済みの動画は最初から再生できます。

プレイリストとクイックコントロールは同時には開きません。クイックコントロールには、速度、音量、ズーム、パン感度、字幕表示、字幕タイミング、音声トラック、字幕トラック、片手レイアウト、プライベート再生、ファイルまたはフォルダを開く、フォルダアクセス、プレイリスト、言語、ショートカットのカスタマイズの 15 項目があります。固定表示の **Settings…** フッターもキーボードで選択できます。

字幕ボタンは字幕表示を直接切り替えます。速度ボタンは速度行を選択したクイックコントロールを開き、左右のナビゲーションキーで 0.1 倍刻みに調整できます。

### ショートカットのカスタマイズ

**Settings → Shortcuts** では、29 の操作を検索し、左右の手ごとに独立した割り当てを記録できます。文字、数字、ファンクションキー、修飾キーとの組み合わせに対応します。Esc で記録をキャンセルし、Delete で編集可能な主キー割り当てを解除できます。競合する割り当てと予約済みのショートカットは受け付けません。固定のナビゲーションキーとメニューの別名キーは引き続き利用できます。変更は即座に反映され、ローカルに保存されます。

## 音量、履歴、プライバシー

音量はプライベート再生を含むすべてのファイルで共有するプレーヤー全体の設定で、アプリを再起動しても維持されます。古いブックマークの音量フィールドは形式の互換性のために残していますが、復元には使用しません。

通常の再生では、最近の 30 ファイルを `~/Library/Application Support/PalmPlayer/history.json` に記録します。再生位置、速度、字幕タイミングと表示状態、選択した音声・字幕トラックを復元します。再生を終えたファイルは先頭から再開します。履歴の書き込みはバックグラウンドで行います。以前の PalmPlayer という名称との互換性を保つため、元のアプリケーション識別子と履歴の保存場所を維持しています。

標準のローカルビルドは選択したファイルをすぐに開き、その後、再生を妨げずに同じフォルダの動画と対応する字幕を検索します。検索はそのフォルダ内に限り、隠しファイルとサブフォルダを除外し、エピソード 1、2、10 のような自然順で並べます。複数のファイルを明示的に選択した場合は選択順を維持します。動画が終わるとキューの次の項目に進みます。

プライベート再生を有効にすると、それまでの通常再生の進捗を保存してから、新しく開くファイルの再生履歴の読み書きを停止します。それらのファイルは先頭から始まり、既存の履歴は残ります。共通の音量とアプリの設定は引き続き保存されます。視聴履歴は **File** メニューから削除できます。

## トラックパッドとプレビュー

動画上でピンチすると、ポインタを中心にズームします。拡大中はトラックパッドを押し込まずに 2 本指で滑らせると、映像を動かせます。動きは指に追従し、指を離すと止まります。パン感度は 25% から 150% の範囲で調整でき、既定は 100% です。映像は表示範囲の境界を越えず、動画を切り替えるとズームとパンをリセットします。

`=`（または `+`）で拡大し、`-` で縮小します。100% から 500% の範囲で 25 ポイントずつ調整でき、長押しすると連続して変わります。片手操作では、左手配置の `2` / `3` で縮小 / 拡大、`1` でウインドウに合わせられます。右手配置では `8` / `9` と `7` を使います。数字キーに修飾キーは不要で、現在の手の配置に従います。対応するズーム操作の主キーが既定値のときに別名キーが有効になり、数字キーを別の操作にカスタマイズ済みの場合はその割り当てを優先します。ズームの主キーは引き続き設定で変更できます。

2 本指でダブルタップすると、2 倍ズームとウインドウに合わせる表示を切り替えます。`0` / `⌘0` でもリセットできます。プレイリスト、コントロール、ヘルプサイドバーの上で始めたジェスチャーは、その領域の操作として処理します。

タイムラインのサムネイルは独立した低解像度デコーダーとメモリ内キャッシュを使用し、メイン動画の再生位置には影響しません。プレイリストの動画プレビューも独立し、音声を無効にしています。プレビュー画像をディスクに書き込むことはありません。

## 操作できる HTML プロトタイプ

フロントエンドのみのプロトタイプを [`prototypes/lplayer`](prototypes/lplayer/README.md) に収録しています。ローカルの動画、フォント、アイコンを使用し、npm の依存関係はありません。

```sh
python3 prototypes/lplayer/serve.py
```

<http://127.0.0.1:4178/> を開いてください。プロトタイプの UI は現在中国語です。キーボード操作のコンテキストはネイティブプレーヤーに合わせており、ネイティブのデコードや macOS API が必要な機能にはその旨を表示しています。ローカルファイルはブラウザのオブジェクト URL を通して再生され、アップロードされません。対応フォーマットはブラウザと libmpv で異なります。ネイティブの履歴やファイルアクセス権のバックエンドは実装していません。

同梱の 3 本のデモ動画は、AI 生成の風景静止画に FFmpeg でゆっくりしたカメラ移動を付け、SRT 字幕を加えた無音クリップです。**現地で撮影した映像ではありません。** [デモの出典](Resources/Demo/README.txt)を参照してください。

## 検証

追加の再生チェックには FFmpeg のコマンドラインツールが必要です。

```sh
brew install ffmpeg
./scripts/check-core.sh
./scripts/check-viewport.sh
./scripts/make-demo.sh
./scripts/check-engine.sh
./scripts/check-gestures.sh
./scripts/check-thumbnails.sh
./scripts/check-seeking.sh production-final Sources/PalmPlayer
python3 scripts/interaction/run-controller.py
```

コアチェックはキー割り当て、修飾キー、履歴、永続化、ショートカット移行を検証します。[コントローラーフィクスチャ](scripts/interaction/README.md)は、生成したメディアと分離したストレージを使って実際のハンドラーを実行し、履歴のあるファイル間や再起動後の共通音量も検証します。生成レポートは Git の対象外である `artifacts/` に保存します。過去の検証資料はソースに同梱していません。

エンジンとジェスチャーのチェックでは、独立したテストウインドウが短時間表示される場合があります。非表示のコントローラーフィクスチャはローカルイベントを使用するため、物理キーボード入力、前面ウインドウのフォーカス、フルスクリーンの Spaces、システムダイアログの動作を保証するものではありません。これらのチェックは実機や実際のメディアによるテストの代わりにはなりません。過去の測定値と範囲は[パフォーマンスノート（中国語）](docs/PERFORMANCE.md)を参照してください。

## サンドボックスのプレビューと配布

別途用意したサンドボックスのプレビューは、管理された依存関係と独立したアプリ識別子・コンテナを使用します。ドキュメント上の対象環境は Apple Silicon と macOS 15 以降です。Mac App Store への提出や承認は受けていません。

```sh
./scripts/build-store-deps.sh
./scripts/build-store-app.sh --preview
./scripts/check-store-app.py
```

サンドボックスでは、最初は選択したファイルだけを再生します。`⌘⇧O` でフォルダへの読み取り専用アクセスを許可すると、同じフォルダの動画と対応する字幕を利用できます。アクセス権にはセキュリティスコープ付きブックマークを使用し、File メニューから削除できます。プライベートモードは永続的なアクセス権や視聴履歴を追加しません。

標準ビルドは、実行ファイルが実際に使用するシステム外のライブラリを同梱し、ロードパスを書き換え、検証したうえでアドホック署名します。ビルドはバックアップを保存してから `dist/LPlayer.app` をアトミックに置き換え、起動中のプレーヤーを再起動しません。同梱の Manrope フォントをシステムにインストールする必要はありません。

依存関係のバージョンとライセンス表記は [`Resources/licenses`](Resources/licenses/README.md) にあります。Homebrew を使う標準ビルドには GPL ライセンスのコンポーネントが含まれます。サンドボックスは別の依存関係構成です。同梱のライセンス表記だけでは、対応するソースコードの完全な配布にはなりません。[リリース準備（中国語）](docs/APP_STORE_RELEASE.md)と[過去のサンドボックス検証（中国語）](docs/APP_STORE_VALIDATION.md)を参照してください。

レンダラーは現在、libmpv の OpenGL パイプラインを使用しています。Metal レンダリング、オンライン字幕検索、字幕タイミングの自動調整、AI 機能は未実装です。HDR の正確性、音声パススルー、すべてのコーデック、機種ごとの消費電力は包括的には検証していません。
